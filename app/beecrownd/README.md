# Beecrowd

## 📖 Visão Geral

Esta seção abriga soluções para problemas da plataforma **Beecrowd** (BeeCrowd é uma plataforma online de programação competitiva brasileira). Aqui você encontrará exercícios resolvidos em diferentes categorias, desde lógica básica até estruturas de dados e SQL.

## 🎯 Objetivos

- ✅ Resolver problemas progressivos de lógica de programação
- 📈 Praticar diferentes paradigmas de programação
- 💾 Trabalhar com estruturas de dados e algoritmos
- 🗄️ Dominar consultas SQL e manipulação de dados
- 🧠 Consolidar conhecimento através de exercícios práticos

## 📁 Organização

Os problemas estão organizados em pastas temáticas:

| Pasta | Descrição | Status |
|-------|-----------|--------|
| **logica/** | Problemas de lógica básica e cálculos | Em progresso |
| **matematica/** | Problemas que envolvem conceitos matemáticos | Planejado |
| **strings/** | Manipulação e processamento de strings | Planejado |
| **estruturas/** | Estruturas de dados avançadas | Planejado |
| **paradigmas/** | Diferentes paradigmas de programação | Planejado |
| **sql/** | Consultas e manipulação de banco de dados | Em progresso |
| **ad-hoc/** | Problemas diversos e desafios | Planejado |
