# LeetCode

## 📖 Visão Geral

Esta seção abriga soluções para problemas da plataforma **LeetCode**, uma das maiores plataformas de preparação para entrevistas técnicas e prática de algoritmos. Aqui você encontrará exercícios resolvidos em diferentes categorias, desde arrays e strings até estruturas avançadas como árvores e grafos.

## 🎯 Objetivos

- ✅ Dominar algoritmos fundamentais e estruturas de dados
- 🎓 Preparação para entrevistas técnicas
- 💡 Desenvolver pensamento crítico em resolução de problemas
- ⚡ Otimizar soluções com melhor complexidade de tempo e espaço
- 🏆 Progressão através de diferentes níveis de dificuldade
